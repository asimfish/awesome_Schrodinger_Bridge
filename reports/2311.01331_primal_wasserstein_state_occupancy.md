## 一句话总结

PW-DICE 把 offline imitation from observation 写成 primal Wasserstein state occupancy matching 问题，在没有 expert action、且不能在线交互的情况下，从专家状态轨迹和离线数据中学习策略。

## 解决的问题

Learning from Observation 的目标是只看专家状态序列，不看动作。机器人场景里这很常见：人类视频、第三方演示或历史录像很难提供 action label。更难的是 offline setting：不能让 agent 在线探索，只能利用已有离线数据。传统 adversarial 或 f-divergence matching 在 support mismatch 下不稳定，Wasserstein 距离因为利用几何结构更适合处理状态分布差异。

## 方法核心

PW-DICE 直接优化 primal form 的 Wasserstein distance，用 state occupancy matching variable 表示 learner occupancy 和 expert occupancy 的运输关系。它结合 DICE-style offline distribution correction，使策略学习不需要在线采样。论文强调它比 dual Wasserstein / Rubinstein critic 类方法更灵活，尤其在 ground metric 选择上。

本质上，它把 imitation from observation 变成“在离线数据支撑上重加权，找到能把 learner occupancy 运到 expert occupancy 的策略”。

## 实验与结果

论文在 ICML 2024 setting 下做了多个 offline LfO 实验，报告 PW-DICE 相比已有 Wasserstein-based 或 DICE-based baselines 更稳。对当前方向来说，重要性在于它提供了一个 offline 形式：不需要目标域交互，也不需要专家动作。

## 与当前方向的关系

这篇对 human video -> robot 的关系是间接但重要的。若我们有大量 human observation 或 real robot passive videos，但没有动作标签，PW-DICE 提供了 occupancy matching 的理论和算法接口。它也能作为 TemporalOT/RHyME 的 offline counterpart。

对于 `SB-Render-Lite`，如果 translated sim frames 只作为 observation augmentation，而 action labels 不完全可靠，可以考虑 occupancy-level evaluation，而不是只训练 BC。

## 局限性

PW-DICE 默认 expert 和 learner 的 state representation 可比较；如果 human video 和 robot proprioception/vision 空间差异很大，还需要 representation alignment 或 GW/OT preprocessing。它偏 offline RL 理论，真实机器人大规模视觉输入还需要额外工程。

## 可借鉴点

- 从 observation-only 数据学习时，state occupancy matching 是关键抽象。
- Wasserstein primal 形式比 adversarial critic 更直观，适合与显式 ground metric 结合。
- 可作为 human passive video 数据的 offline imitation baseline。
