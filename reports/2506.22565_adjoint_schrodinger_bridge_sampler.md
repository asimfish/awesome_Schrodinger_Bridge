# Adjoint Schrödinger Bridge Sampler

## 基本信息

- 论文：Adjoint Schrödinger Bridge Sampler
- 方法名：ASBS
- 作者：Guan-Horng Liu, Jaemoo Choi, Yongxin Chen, Benjamin Kurt Miller, Ricky T. Q. Chen
- 会议：NeurIPS 2025
- 链接：https://arxiv.org/abs/2506.22565

- 本地 PDF：`../papers/2506.22565_adjoint_schrodinger_bridge_sampler.pdf`
- 中文译本：[`../papers_zh/2506.22565_adjoint_schrodinger_bridge_sampler.zh.pdf`](../papers_zh/2506.22565_adjoint_schrodinger_bridge_sampler.zh.pdf)（保版式机器翻译，QA 见 [QA_REPORT](../papers_zh/QA_REPORT.md)；引用以英文原文为准）
- 归类：Boltzmann sampling；Schrödinger Bridge；Adjoint Matching；arbitrary prior。

## 一句话总结

ASBS 把 Adjoint Sampling 从“固定 Dirac 初态”推广到任意 source prior，并通过 Adjoint Matching 与 Corrector Matching 的交替优化求解一般 Schrödinger Bridge，在不估计目标样本或 importance weight 的前提下学习能量分布 sampler。

## 解决的问题

Adjoint Sampling 虽然节省能量评估，但其 memoryless 条件把初始分布限制为 Dirac delta，无法利用 Gaussian、harmonic oscillator 或已有模拟器产生的 domain-specific prior。另一方面，能处理任意先验的 Sequential SB 等方法通常依赖 SMC 或 importance weight，扩展性差。

ASBS 要同时满足四点：非 memoryless 动力学、任意先验、简单 matching loss、训练时不依赖 importance weight。

## 方法核心

论文直接考虑一般 SB：在 `X_0 ∼ μ`、`X_1 ∼ ν` 的边界约束下，寻找相对 base process 路径 KL 最小的控制 SDE。目标 `ν` 仍只由未归一化能量 `E(x)` 给出。

算法交替执行两类回归：

- Adjoint Matching 学控制器，使当前过程朝能量定义的终端分布移动；
- Corrector Matching 学一个校正项，消除任意初始先验和非 memoryless reference 带来的偏差。

作者证明这一交替过程等价于 Iterative Proportional Fitting 的两个 half-bridge 投影，因此固定点收敛到全局 SB 解。相较 AS，多一个 corrector 网络带来小幅开销，但换来更自由的 prior 和 noise schedule。

## 实验与结果

ASBS 在 MW-5、DW-4、LJ-13、LJ-55 上均取得表中最佳结果。例如 LJ-13 的样本/能量 `W2` 为 `1.59/1.99`，优于 AS 的 `1.67/2.40`；LJ-55 为 `4.00/28.10`，也优于 AS 的 `4.04/30.83`。

在 alanine dipeptide 的五个扭转角边缘和 `(ϕ, ψ)` 联合分布上，ASBS 的 KL/W2 最低；但 Ramachandran 图仍漏掉少数低密度模态。摊销构象生成中，harmonic prior 的 ASBS 在不做 RDKit warm-start 时已接近或超过 warm-start 的 AS，说明结构化先验确实改善探索。

## 与 Adjoint Sampling 的关键区别

AS 是 ASBS 在 `(base drift, source prior) = (0, Dirac)` 下的特例。ASBS 的主要贡献不是换一个更大的网络，而是解除 memoryless 条件，允许用贴近问题结构的 source prior；Corrector Matching 是为这一自由度付出的必要代价。

## 与当前 sim2real 方向的关系

对 sim2real 最关键的是“任意先验”：source 不必是白噪声，可以直接是 sim latent、sim transition 或物理先验；target 则可由真实感与任务一致性能量定义。这比原始 AS 更接近 `sim distribution → real-like distribution`。

不过 ASBS 仍是 energy-based sampling，而不是两端都有样本的标准 domain translation。若真实域有大量无配对样本，GSBM/SB Flow 更直接；若真实样本稀少但能训练可靠能量模型，ASBS 才更有优势。

## 局限性

- SOC/反向 KL 的 mode-seeking 仍会漏掉低密度模态，作者也建议结合 importance sampling。
- 多一个 corrector 网络和交替阶段，训练与调参比 AS 更复杂。
- 实验集中于分子/经典能量，没有视觉、机器人或高维真实控制数据验证。
- 效果依赖 source prior 是否真正包含有用结构；差先验也可能增加 bridge 难度。

## 可借鉴点

- 把 sim 数据本身当作 source prior，而不是先扩散到完全无结构的 Gaussian。
- 用 domain-specific harmonic/kinematic prior 改善探索，并做 Gaussian prior 对照。
- 将“目标样本充足”和“只有目标能量”作为两种不同实验设定，分别选择 GSBM/SB Flow 与 ASBS。
