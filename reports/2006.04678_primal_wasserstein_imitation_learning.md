# Primal Wasserstein Imitation Learning

## 基本信息

- 论文：Primal Wasserstein Imitation Learning
- 方法名：PWIL
- 作者：Robert Dadashi, Léonard Hussenot, Matthieu Geist, Olivier Pietquin
- 会议：ICLR 2021
- 链接：https://arxiv.org/abs/2006.04678
- 本地 PDF：`../papers/2006.04678_primal_wasserstein_imitation_learning.pdf`
- 中文译本：[`../papers_zh/2006.04678_primal_wasserstein_imitation_learning.zh.pdf`](../papers_zh/2006.04678_primal_wasserstein_imitation_learning.zh.pdf)（保版式机器翻译，QA 见 [QA_REPORT](../papers_zh/QA_REPORT.md)；引用以英文原文为准）
- 归类：OT imitation foundation；state-action distribution matching。

## 一句话总结

PWIL 用 primal Wasserstein distance 匹配 expert 和 agent 的 state-action distributions，并把距离上界转成在线 reward，是后续 ROT、TemporalOT 等 OT imitation 方法的重要基础。

## 解决的问题

传统 GAIL/AIRL 等 adversarial imitation 多使用 f-divergence 或 learned discriminator，训练可能不稳定，且对 support mismatch 敏感。Wasserstein distance 是真正的几何距离，可以在 state-action space 中利用样本之间的距离结构。PWIL 试图用一个概念简单的 primal formulation 来实现 imitation。

## 方法核心

论文把 expert demonstrations 看作 state-action empirical distribution，把 agent rollout 看作另一个 distribution。目标是最小化二者的 Wasserstein distance。由于直接优化完整 Wasserstein 难，PWIL 推导了一个可在线计算的上界，并将其转换为 reward：agent 每访问一个 state-action pair，就根据它与 expert samples 的 transport matching cost 获得奖励。

重要的是，PWIL 不需要训练 discriminator；reward 直接来自几何距离和 transport matching。

## 实验与结果

论文在 MuJoCo continuous control 中展示样本效率，论文（引言与结论）强调其为首个用单条 subsampled demonstration 让 Humanoid 跑起来的方法。主实验为低维状态输入，但论文另含一个从 pixel 学 metric 的视觉实验作 proof-of-concept：Adroit door opening（人类经 Haptix 生成示范、无动作纯视觉的 LfO 设定），用 TCC 自监督学习的 embedding 作 ground metric，door/handle 位置随机并验证了泛化。它奠定了“OT distance -> imitation reward”的方法模板。

## 与当前方向的关系

PWIL 是本目录中最基础的一篇。后续 ROT 把它和 BC regularization 结合；TemporalOT 把它扩展到 video trajectory reward；PW-DICE 把它改造成 offline observation matching。理解 PWIL 有助于看清这些后续方法的共同结构。

## 局限性

PWIL 默认 expert 和 agent 的 state-action space 可比较，因此不直接解决 human video/robot action 空间不一致的问题。它也需要在线 rollout 来计算 reward，不是纯 offline 方法。视觉高维输入下 ground metric 设计仍是难点，但论文的 TCC pixel-metric door 实验已给出一个可行的正面样例（自监督 embedding 作 metric），并非完全未解。

## 可借鉴点

- OT imitation 的最小公式：匹配 expert/agent state-action distributions。
- Reward 可以直接从 transport cost 构造，不一定要 adversarial discriminator。
- 对机器人跨域迁移，关键扩展是 representation 和 cost，而不是 OT 框架本身。
