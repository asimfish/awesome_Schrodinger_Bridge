## 一句话总结

GWIL 把 cross-domain imitation formalize 成 Gromov-Wasserstein optimal transport 问题，使 learner 可以从不同状态空间、甚至不同维度的 expert demonstrations 中学习，而不需要预先给出跨域 state mapping。

## 解决的问题

经典 imitation learning 默认 expert 和 learner 在同一 observation/action space 中。但在具身迁移中，expert 可能是人类、不同机器人、不同传感器或不同环境。状态空间不仅数值不同，维度也可能不同；要求人工设计映射或收集 proxy task demonstrations 会严重限制应用。

GWIL 的目标是：不直接比较 state feature，而比较各自轨迹内部的 relational structure。只要两个 domain 中的任务结构相似，就可以通过 Gromov-Wasserstein 对齐。

## 方法核心

普通 Wasserstein 需要定义跨域样本之间的 ground cost；当两个 domain 状态空间不同，这个 cost 很难定义。Gromov-Wasserstein 则比较两个分布内部 pairwise distance structure，因此适合没有显式 correspondence 的跨域问题。

GWIL 用 GW distance 比较 expert 和 learner 的 stationary state-action distribution。RL 训练时，learner policy 被优化为让自身诱导的分布与 expert distribution 在 GW 意义下接近。这样，算法不需要知道 expert 的某个 state 应该对应 learner 的哪个 state，而是通过结构相似性寻找对齐。

## 实验与结果

论文在连续控制 benchmark 中验证，从简单 rigid transformation 到更任意的 domain transformation。摘要强调 GWIL 在没有 proxy tasks 的情况下能处理 non-trivial continuous control domains。它给出了一个重要基线：如果 human 和 robot 的原始 observation 不可比，Gromov-Wasserstein 是比普通 feature matching 更自然的形式。

## 与当前方向的关系

GWIL 是人类/机器人跨域 imitation 的理论基础之一。它对当前 本库 的价值在于区分两类问题：

1. sim-real 视觉差异：状态空间结构相同，普通 OT / SB Flow 可以直接做 feature transport；
2. human-robot embodiment 差异：状态空间和动作空间可能不同，需要 GW / structure-aware transport。

如果我们后续从 sim RGB -> real RGB 升级到 human video -> robot trajectory，可能需要把 SB/OT 的 cost 从直接 feature distance 扩展成 GW-like relational cost。

另注：Learn what matters（TRE，NeurIPS 2022）在 MuJoCo 跨形态实验中直接以 GWIL 为基线，两者构成「GW 结构对齐 vs 任务相关表示」两条路线的直接实验对照，详见[该报告](./2209.12093_task_relevant_embeddings_cross_domain_il.md)。

## 局限性

GW 计算复杂，且优化时与 RL policy coupling 后更难训练。论文主要在 benchmark continuous control 上验证，离大规模真实机器人视觉数据仍有距离。GW 依赖内部距离结构，如果 representation 或 distance metric 不包含任务语义，结构对齐仍会失败。

## 可借鉴点

- 跨 embodiment 时优先考虑 relational alignment，而不是强行定义逐点 feature distance。
- GW 可以作为 human/robot latent transport 的 cost 或 regularizer。
- 对 SB-Render-Lite 的下一阶段，GW 思路适合处理不同机器人或 human-to-robot 的 motion structure transfer。
