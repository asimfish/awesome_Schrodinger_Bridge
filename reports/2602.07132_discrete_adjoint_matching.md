# Discrete Adjoint Matching

## 基本信息

- 论文：Discrete Adjoint Matching
- 方法名：DAM
- 作者：Oswin So, Brian Karrer, Chuchu Fan, Ricky T. Q. Chen, Guan-Horng Liu
- 会议：ICLR 2026
- 链接：https://arxiv.org/abs/2602.07132
- 本地 PDF：`../papers/2602.07132_discrete_adjoint_matching.pdf`
- 中文译本：[`../papers_zh/2602.07132_discrete_adjoint_matching.zh.pdf`](../papers_zh/2602.07132_discrete_adjoint_matching.zh.pdf)（保版式机器翻译，QA 见 [QA_REPORT](../papers_zh/QA_REPORT.md)；引用以英文原文为准）
- 归类：discrete generative model fine-tuning；CTMC；entropy-regularized reward optimization。

## 一句话总结

DAM 为连续时间 Markov 链定义“离散 adjoint”，把连续空间的 Adjoint Matching 推广到不可微的 token 空间，用于以任意终端 reward 对 masked diffusion/LLM 做 KL 正则化微调。

## 解决的问题

连续 Adjoint Matching 依赖状态、控制和终端损失的梯度；离散 token 空间不存在这些导数，生成模型也从 SDE 变成 CTMC transition rate。因而不能把连续 AM 的 adjoint ODE 直接离散化。

论文关注的任务是 `min E[g(X_1)] + KL(p^u || p^base)`：以预训练离散生成模型为 base，在不偏离 base 太远的同时提高终端 reward。它与“从未归一化离散能量中采样”相关，但更直接的定位是 post-training / reward fine-tuning。

## 方法核心

DAM 从统计估计而非微分控制论出发。作者利用 Dynkin 公式，把最优 CTMC rate 表示为当前过程下某个可估计量的条件期望，并将该估计量定义为 discrete adjoint。随后用 matching regression 求 transition rate 的固定点。

面对词表和序列构成的巨大状态空间，论文利用 masked CTMC 的结构简化可达转移，并加入 importance weighting 与降方差设计。理论上，matching 目标的唯一固定点对应熵正则 reward optimization 的最优 transition rate。

## 实验与结果

在 91×91 离散 Checkerboard/Pinwheel 上，DAM 比 D1、SVDD 更稳定地逼近可解析的最优分布。

在 LLaDA-8B-Instruct 上，论文分别针对 GSM8K、MATH500、Countdown 和 4×4 Sudoku 做 reward fine-tuning。128 长度下，Sudoku 准确率从 base 的 11.5%、D1 的 23.8% 提升到 DAM 的 89.2%；Countdown 从 34.8%/43.8% 提升到 60.2%。GSM8K 和 MATH500 的提升较温和，且 256 长度的 MATH500 略低于 D1。跨 128/256/512 测试长度时，DAM 在 Sudoku/Countdown 上仍保持明显优势。

## 与 Discrete ASBS 的区别

`DAM` 以一个 pretrained CTMC 为 base，通过终端 reward 做 KL 正则微调，实验对象包括 diffusion LLM；`Discrete ASBS` 则求解离散 Schrödinger Bridge，从未归一化能量定义的目标分布采样，依赖 group/additive reference 结构，实验集中于 Ising/Potts。两者不能因名字相近而视作同一算法。

## 与当前 sim2real 方向的关系

DAM 对 RGB transport 不直接，但适合离散动作 token、技能序列或离散 world-model rollout 的 reward fine-tuning。可将真实域成功率、可执行性或安全约束作为终端 reward，在保留 simulation 生成模型先验的同时调整离散策略分布。

## 局限性

- 当前大模型实验主要利用 masked CTMC 结构；推广到 non-masked CTMC 仍是未来工作。
- 在 GSM8K/MATH500 上优势不稳定，说明任务相关近似和 reward 设计仍重要。
- importance weighting 在大离散空间可能产生高方差。
- 只优化终端 reward 时，长序列的中间安全性和动力学约束未被直接建模。

## 可借鉴点

- 对离散 action/skill token 采用 CTMC rate matching，而不是把 token 强行连续化。
- 使用 KL-to-base 明确保留 simulation policy/model 的已有能力。
- 同时评估训练长度内性能和跨长度泛化，避免 reward fine-tuning 只记住固定 horizon。
