## 一句话总结

React-OT 将给定反应物/产物的 transition-state 搜索写成确定性动态 OT，从二者的线性插值出发，用 object-aware SE(3)-equivariant vector field 直接运输到过渡态，在保持高精度的同时把 OA-ReactDiff 的多次随机采样与排序变成约 0.4 秒的一次确定性生成。

## 解决的问题

化学 transition state 是势能面的一级鞍点，传统 DFT+NEB 等算法精确但昂贵。OA-ReactDiff 能生成反应物、TS 和产物，但在已知两端的 double-ended search 中仍从 Gaussian 随机初始化，需要多次采样和额外 recommender 选最优解。

当反应物与产物都已给定时，任务更接近一个条件明确、期望输出唯一的 transport，而不是需要高随机性的无条件生成。

## 方法核心

React-OT 固定反应物与产物，把它们的线性插值作为 TS 初始猜测，学习一个类似 flow matching 的确定性 ODE 将该结构运输到真实 TS。模型沿用 object-aware LEFTNet，对同一反应中不同分子对象保持所需的平移、旋转、置换等对称性。

这一设计把 diffusion SDE 改成 OT ODE：没有随机噪声，不需要从 40 个候选中排名，也把 denoising model 的调用从约 40,000 次降到 50 次。论文还先在 760,615 条较低精度的 RGD1-xTB 反应上预训练，再用 DFT 级 Transition1x 微调。

## 实验与结果

在 1,073 条留出反应上，React-OT 的 TS 中位 RMSD 为 `0.0527 Å`、势垒高度中位误差为 `1.058 kcal/mol`，63.6% 达到 1.58 kcal/mol 的 chemical accuracy，推理约 `0.39 s`。加入 xTB 预训练后，中位 RMSD/势垒误差进一步到 `0.0441 Å / 0.741 kcal/mol`，chemical accuracy 为 71.9%。

即使输入改为更便宜的 xTB 优化反应物/产物，中位 RMSD/势垒误差仍为 `0.0487 Å / 0.787 kcal/mol`。与置信度模型和 DFT fallback 结合后，86% 的 TS 由 React-OT 生成，整体达到 chemical accuracy，计算成本约为全 DFT workflow 的七分之一。

## 与 SB 的关系

React-OT 使用确定性 OT/flow matching，不是 entropy-regularized Schrödinger Bridge。它展示了一个重要边界：当输入两端信息充分、输出近似唯一且随机性没有价值时，OT-ODE 可能比 stochastic SB 更高效；当映射一对多或需要覆盖多模态时，diffusion/SB 仍更合适。

## 与当前 sim2real 方向的关系

React-OT 最值得借鉴的是“从结构化 source guess 出发”和“把物理对称性写进 vector field”。对 sim2real，可以从 sim frame/latent/trajectory 本身出发，学习最短 task-preserving transport，而不是先破坏成 Gaussian noise。

对于配对较强、映射接近确定性的 sensor correction 或渲染差距，可加入 OT-ODE baseline；对于 unpaired、one-to-many 的真实域风格或动力学，则仍应使用 SB。

## 局限性

- 展示范围主要是只含 C/N/O/H 的中性有机反应，缺少带电物种和金属催化体系。
- double-ended TS 近似唯一，确定性很合适；产品生成等一对多任务不适用。
- 反应物/产物构象优化仍是整个 workflow 最耗时环节。
- 训练依赖成对的反应物—TS—产物数据，不能直接解决无配对迁移。

## 可借鉴点

- 将确定性 OT-ODE 纳入 SB 的必要对照，检验随机性是否真的有用。
- 使用 source/target 结构构造强初始猜测，减少 NFE。
- 同时报告结构误差、下游物理量误差、推理时间和 fallback 后的系统总成本。
