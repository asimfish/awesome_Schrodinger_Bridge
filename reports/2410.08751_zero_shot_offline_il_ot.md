# Zero-Shot Offline Imitation Learning via Optimal Transport

## 基本信息

- 论文：Zero-Shot Offline Imitation Learning via Optimal Transport
- 作者：Thomas Rupf, Marco Bagatella, Nico Gürtler, Jonas Frey, Georg Martius
- 会议：ICML 2025
- 链接：https://arxiv.org/abs/2410.08751
- 本地 PDF：`../papers/2410.08751_zero_shot_offline_il_ot.pdf`
- 中文译本：[`../papers_zh/2410.08751_zero_shot_offline_il_ot.zh.pdf`](../papers_zh/2410.08751_zero_shot_offline_il_ot.zh.pdf)（保版式机器翻译，QA 见 [QA_REPORT](../papers_zh/QA_REPORT.md)；引用以英文原文为准）
- 归类：zero-shot offline imitation；goal abstraction；OT planning。

## 一句话总结

这篇论文用 Optimal Transport 把 expert demonstration 的目标序列转成 occupancy-level imitation objective，并结合 offline learned dynamics / planning，让 agent 在测试时从少量甚至单条 demonstration 中 zero-shot 模仿新行为。

## 解决的问题

Zero-shot imitation 希望测试时只给一个 demonstration，就能复现 unseen behavior。很多方法依赖大量 expert data 或在线 fine-tuning；offline setting 下还不能和环境大量交互。论文指出，简单把 demonstration 解释为一串局部目标会导致 myopic behavior：agent 追逐最近目标，而不是匹配整体 occupancy 或任务过程。

## 方法核心

论文把 GC-RL 内在的 state-goal distance（即离线学到的 goal-conditioned value function）提升（lift）为 occupancy 之间的距离：用该 value function 作 OT 的 ground cost，因此 cost 自带环境动力学信息，而非通用欧氏/余弦距离；expert 目标序列与策略 occupancy 之间的 OT 用 Sinkhorn 求解，occupancy 由 TD-MPC2 世界模型在 latent space rollout 近似，动作由 iCEM 零阶优化器在固定 horizon 的 MPC 框架内产生，而不是逐点贪心跟踪。

核心思想是：专家 demonstration 不只是目标点列表，而是一条分布轨迹；zero-shot imitation 应该匹配这条轨迹诱导的 occupancy。

## 实验与结果

论文在多个 robotic simulation / control 任务中与 zero-shot IL baseline 对比。正文表明方法在 robotic manipulation example 和 goal abstraction setting 下优于 myopic goal-reaching 方法。因为它是 ICML 2025 论文，和当前机器人 foundation policy / offline data 方向比较接近。

## 与当前方向的关系

这篇不直接做 human-to-robot 或 sim-to-real domain adaptation，但它补上了“只给 demonstration，如何用 OT 做 zero-shot task specification”的环节。若未来我们把 human video prompt 转成 latent goal sequence，可以用类似 OT occupancy matching 让 robot policy 追踪整体任务分布。

## 局限性

方法需要可用的 goal abstraction 和合适的 distance metric。若 abstraction 不包含任务关键因素，OT objective 会失真。它主要在 simulation/offline control 上验证，真实多模态人类视频到机器人仍需要 representation 和 embodiment 对齐。

## 可借鉴点

- 不要把 video prompt 只拆成逐帧目标；应匹配 occupancy / trajectory distribution。
- OT 可以作为 demonstration-to-policy planning objective。
- 可与 RHyME 的 video retrieval 结合：先检索等价 robot clips，再用 OT occupancy objective 规划。
